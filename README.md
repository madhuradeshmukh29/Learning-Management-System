# LearnHub – Learning Management System

## About the Project
LearnHub is a web-based Learning Management System (LMS) developed using Java Spring Boot and MySQL. It allows students to register, log in, explore courses, enroll in courses, access lessons, complete quizzes, and track their quiz results.

## Features
- Student Registration and Login
- Secure Password Storage
- Course Listing
- Course Enrollment
- Lesson Viewing
- Lesson Completion Tracking
- Course-based Quizzes
- Automatic Quiz Score Calculation
- Quiz Result History
- Clear All Quiz History
- Logout Functionality

## How to Run the Project

1. Clone or download the project.
2. Open the project in Visual Studio Code.
3. Create a MySQL database named `lms_db`.
4. Configure the database username and password in `application.properties`.
5. Open the terminal in the project folder.
6. Run the following command:

```bash
.\mvnw.cmd spring-boot:run
```

7. Open the browser and visit:

```text
http://localhost:8081/login.html
```

## Project Objective
The objective of this project is to provide a simple online learning platform where students can access courses, learn through lessons, practice quizzes, and track their learning progress.
